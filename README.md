# DevOps Lab

A collection of command-line tools for DevOps and site reliability engineering (SRE).

| Project | Purpose |
| --- | --- |
| [Log Triage](log-triage/) | Inspect log formats, summarize and search events, reconstruct timelines, and compare or gate event rates with versioned JSON and exit codes. |
| [FIX Printer](fix-printer/) | Find orders in FIX 4.2 and 4.4 logs and decode matching messages into readable tag tables. |

See each project README for usage examples and test commands.
