# DevOps Lab

A collection of command-line tools for DevOps and site reliability engineering (SRE).

| Project | Purpose |
| --- | --- |
| [Log Triage](log-triage/) | Inspect log formats, summarize and search events, reconstruct timelines, and compare or gate event rates with versioned JSON and exit codes. [Install](log-triage/README.md#download-and-install) / [Release](https://github.com/cicarellous/devops-lab/releases/tag/log-triage-v0.1.0) / [Docs](log-triage/docs/) |
| [FIX Printer](fix-printer/) | Find orders in FIX 4.2 and 4.4 logs and decode matching messages into readable tag tables. [Install](fix-printer/README.md#download-and-install) / [Release](https://github.com/cicarellous/devops-lab/releases/tag/fix-printer-v0.1.1) / [Docs](fix-printer/docs/) |

See each project README for usage examples and test commands.
